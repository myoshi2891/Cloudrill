## 1. シナリオと観点

利用者が模試の途中でアプリを離れ、あとで戻る。離れ方と戻り方の組み合わせを確認する。

- **離れ方**: 強制終了、バックグラウンド、画面のロック、端末の再起動、OS によるメモリ不足での終了、試験の切り替え。
- **離れたタイミング**: 解答の直後、見直しの一覧、提出の確認中。
- **戻ったとき**: 制限時間の前、制限時間の後。
- **復元する内容**: 解答、フラグ、現在の問題、残り時間(離れていたあいだも進む)。

自動の UI テストは、`-store-path` で保存先を固定し、`app.terminate()` のあと同じ引数で起動し直す。

## 3. 既存のテストで覆われていない点

- **E2E-02-04、06〜09**: 対応する UI テストを、テスト名からは特定できなかった。振る舞いは機能テスト(FT-02-04、11、14、21)と結合テスト(IT-04-09)で確認している。
- **E2E-02-05、10〜13**: 実機の操作や、端末の状態が必要で、自動化が難しい。解答ごとに保存することは、結合テスト(IT-03-01〜03)で確認している。
- 残り時間の値そのもの(何秒残っているか)を UI テストで確認しているかは、テスト名からは特定できなかった。
