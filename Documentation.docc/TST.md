## 1. 目的

テストの設計は、BDD 11 章(テストの種類と受け入れ基準の対応)、DDD 7 章(TDD の規約)、DDD-P4 の P4-S17・S18、DDD-P5 の P5-S08 に分かれて書かれている。各ステップには Red の表があるが、「機能要件(FR)・受け入れ基準(AC)・エラー(E)ごとに、どのレベルで何を確認し、既存のテストでどこまで覆われているか」を一覧できる文書がなかった。

この文書群は、機能テスト・結合テスト・E2E の 3 レベルについて観点を洗い出し、観点ごとにテスト項目をまとめたものである。2026-11-17 時点の設計と実装を対象にする。設計や実装が変わったら、該当するテスト項目書を更新する。

## 2. テストのレベル

BDD 11.1 には「機能テスト」「E2E」の区分がないため、次のように定義する。

| レベル | 定義 | 主な実施方法 | BDD 11.1 との対応 |
|---|---|---|---|
| 機能テスト(FT) | 1 つの機能要件が仕様どおりに動くかを、機能の単位で確認する。依存は Fake に差し替える | ViewModel・ドメインの自動テスト(Swift Testing)、pytest、足りない分は画面操作 | ユニットテストのうち、機能の振る舞いを見るもの |
| 結合テスト(IT) | 実物どうしをつないだ境界を確認する(Python の生成物と Swift、ファイルシステム、SwiftData、Data と Presentation) | Swift Testing(実ストア・実パック)、契約 fixture | 結合テスト |
| E2E | 実際のアプリで、利用者のシナリオを最初から最後まで通す | XCUITest、実機での手動、ステージング | UI テスト、手動テスト |

純粋なロジックの単体テスト(FSRS の計算、採点の式、出題の選択など)は対象外とし、機能の前提として参照するだけにする。ドメイン層のカバレッジ(NFR-11)は `domain-test.yml` の `scripts/coverage.sh packages/Domain 80` で確認する。

## 4. 書式と凡例

テスト項目書はすべて同じ構成にする。

1. 冒頭の表(上位文書、レベル、対応要件、対象、既存のテスト)
2. テストの観点(何を確かめるか、どの条件の組み合わせを見るか)
3. テスト項目(表)
4. 既存のテストで覆われていない点
5. 未決事項

**テスト項目の ID** は `<レベル>-<テスト項目書の番号>-<連番>`(例: `FT-02-14`、`IT-03-04`、`E2E-01-05`)。

**実施方法**

| 値 | 意味 |
|---|---|
| 自動: `<テスト>` | 既存の自動テスト(Swift Testing・pytest・CI)で確認する。テスト名・ファイル名はリポジトリで実在を確認したもの |
| 自動(UI): `<テスト>` | 既存の XCUITest(`ExamPrepAppUITests/`)で確認する |
| 自動(追加) | 自動テストで確認すべきだが、まだテストがない。対応するステップでテストを追加する |
| 手動 | 実機・Instruments・ステージング・目視などで確認する |

**時期**

| 値 | 意味 |
|---|---|
| 現在 | 今のコードとリポジトリで実施できる |
| P4-S18 | アクセシビリティとスナップショット(DDD-P4 P4-S18)の実装時に実施する |
| P5 | 配信・誤り報告(DDD-P5)の実装時に実施する |
| P6 | 拡張機能(DDD-P6)の実装時に実施する |
| リリース前 | App Store への申請前、または本番環境の構築時に実施する |

**結果**

| 値 | 意味 |
|---|---|
| 未実施 | まだ実施していない。既存の自動テストがある項目も、この文書の作成時には実行していないので「未実施」とする |
| 合格 | 期待結果のとおりだった(実施日と実施者、または CI の実行を併記する) |
| 不合格 | 期待結果と異なった(対応する Issue・PR を併記する) |
| 対象外 | 前提が変わり、実施が不要になった(理由を併記する) |

## 7. 運用

- テストを実施したら、該当する行の「結果」を更新し、実施日と実施者(自動テストは CI の実行)を書く。
- 「自動(追加)」の項目は、対応するステップの Red の表に加え、テストを書いたら実施方法をテスト名に書き換える。
- 「時期」が P4-S18・P5・P6 の項目は、対応するステップの完了条件と合わせて実施する。
