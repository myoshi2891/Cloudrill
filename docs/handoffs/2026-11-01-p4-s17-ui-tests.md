## 残課題

- **起動時間**: Simulator・Debug・UI テスト用の設定で平均 5.28 秒（5.09〜5.82 秒）だった。NFR-01 の 2 秒を大きく上回る。UI テスト用の起動では同梱パックの読み込みと整合確認、作業ディレクトリへの準備が入るので、まず Release の実機で計測し、`ContentBootstrapper` などの起動処理の時間を Instruments で分解する。
- `-network offline` は今は引数の検証だけで、P4 のアプリは通信しない。P5 で通信を追加したら、この引数で通信を止めるようにすること。
